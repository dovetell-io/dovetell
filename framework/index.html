Framework

Make project context easier to resume.

Scattered inputs become reviewed context. Reviewed context becomes recoverable intent.

Inference through convergence.

The framework keeps project context recoverable by moving from scattered inputs to reviewed continuity.

01

Capture

Drop a note, file, decision, or observation before it gets lost.

02

Agent Read

Useful inputs are shaped into proposed context, not treated as truth.

03

Review

A human accepts, edits, rejects, or parks the change.

04

Promote

Accepted context becomes repo-owned project memory.

05

Resume

The next session starts from trusted continuity.

Why it exists
01

Lost Intent

Decisions happen in chats, commits, meetings, and half-finished notes. The next session has to reconstruct the story.

02

Documentation Drift

Docs are useful until the work moves. Without review and ownership, nobody knows what is still true.

03

Unsafe Resume

Agents move fast, but without durable context they repeat old debates, miss constraints, or promote stale assumptions.
